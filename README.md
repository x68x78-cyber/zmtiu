# 自媒体运营工作台（zimeiti-workbench）

DSH Desktop 本地工作台，面向个人博主与小团队。把泛自媒体的「选题 → 脚本 → 发布 → 复盘」主循环做成一个整页操作台，共五个板块：

1. **今日**：灵感速记（可一键转选题）、今天要做的（含逾期/待录数据智能提醒）、连更里程碑徽章、每日激励语。
2. **选题**：每周选题会 4 步方法、三类选题库（爆款/日常/系列/测试）、一句话大纲、本周配比进度、爆款雷达（收集对标爆款并自动聚合钩子类型/平台/赛道的洞察，可一键转选题）。
3. **脚本**：黄金 3 秒开头公式库、爆款结构模板（视频/图文切换）、「AI 指令生成器」（把选题+钩子+结构+要点编排成专家级 prompt 供复制到任意 AI 跑）、我的资产库（可搜索/星级/复制）。
4. **发布**：各平台最佳发布时段、发布排期（逾期红标、可改期/删除、标已发）、发布后黄金 1 小时动作清单。
5. **复盘**：四率看板（完播/互动/关注/转化，视频看完播、图文看收藏率，按形态自动切换）、曝光×涨粉双轴趋势图、归因图（按选题库/钩子/时段/形态/平台切换）、每条内容自动判定爆了/达标/低于预期。

## 技术说明

- **视觉**：珊瑚粉少女风（奶油底 + 珊瑚粉渐变 Hero + 圆润卡片），图表一律原生 SVG 自绘，不引用任何外部 CDN 或字体。
- **存储**：数据存本机浏览器 localStorage（键 `wb_media_studio_v`），自动保存；含示例数据可清空、JSON 备份导入导出、CSV 导出。
- **公开仓库**：https://github.com/x68x78-cyber/zmtiu
- **布局**：`customFrame: true` 整页业务工作台，首次进入即显示业务首页，不依赖会话初始化。
